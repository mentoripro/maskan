# Maskan Premium Hotel Tashkent

Статический сайт отеля. Чистый HTML, CSS и JavaScript — без сборки. Его можно открыть с диска или выложить на GitHub Pages.

## Что внутри

- Главная на русском, узбекском и английском
- Номера, услуги, галерея, карта и заявка в WhatsApp
- Фотографии взяты из публичной карточки отеля

Адрес на сайте: улица Фароби, 400, 100069, Aktepa-Chigatay. Телефон `+998 99 110 37 37`, Telegram [@MASKAN_HOTEL](https://t.me/MASKAN_HOTEL), Instagram [hotel_maskan](https://www.instagram.com/hotel_maskan/).

На картах (2GIS, Яндекс) тот же отель Maskan иногда указан как улица Фароби, 356Б. На сайте стоит адрес из брифа — Фароби, 400. Метка на карте стоит по публичным координатам отеля, чтобы гость попал к зданию. Если дом другой, замените координаты в `index.html`.

Цены 200–400 тысяч сум — ориентир из открытых справочников, не прайс отеля. Заявка с сайта оплату не принимает: она открывает WhatsApp с готовым текстом.

## Как посмотреть локально

Откройте `index.html` в браузере. Карта подгружается из интернета.

## GitHub Pages

1. Создайте репозиторий на GitHub и залейте в него все файлы этого каталога, включая папку `images` и файл `.nojekyll`.
2. Settings → Pages → Branch: `main`, folder: `/ (root)`.
3. Через минуту сайт откроется по адресу `https://<пользователь>.github.io/<репозиторий>/`.

Ссылки в проекте относительные, поэтому сайт работает и как страница пользователя, и как страница проекта.
